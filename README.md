# GQ_Lup_B_analysis_2025
These scripts generate the figures for our ApJ paper ([DOI: insert DOI]) published in The Astrophysical Journal. The main analysis is in Analysis.ipynb. Orbit corner plots and orbit trajectories for the six test cases are located in the plots/ directory. To reproduce similar figures with your own results, replace the example inputs with your orbit-run HDF5 files as indicated in the code.
