# GQ_Lup_B_analysis_2025
These scripts generate the figures for our ApJ paper, "Constraints on the Orbit of the Young Substellar Companion GQ Lup B from High-resolution Spectroscopy and VLTI/GRAVITY Astrometry" [Venkatesan et al., 2025](https://iopscience.iop.org/article/10.3847/1538-4357/ae0c15). The main analysis is in Analysis.ipynb. Orbit corner plots and orbit trajectories for the six test cases are located in the plots/ directory. To reproduce similar figures with your own results, replace the example inputs with your orbit-run HDF5 files as indicated in the code. The zenodo link for the repository can be found  here- [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17087542.svg)](https://doi.org/10.5281/zenodo.17087542)
